# Coxswain M0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `cox` v0.1.0 — a macOS CLI, installable with `brew install hua-ri/tap/coxswain`, that gives a person and AI agents (Claude Code, Codex, Kimi Code) policy-checked, audited access to SSH hosts over CLI and MCP.

**Architecture:** Every capability is an `action.Action` (ID, JSON-Schema input, `Assess` → risk/targets/preview, `Run`) registered once in a `Registry`. `engine.Engine` is the only path to `Run`: assess → `policy.Decide` → (approval record + confirmer) → run → JSONL audit. The CLI command tree and the MCP tool list are generated from the registry. No daemon: each `cox` process holds its own state; shared state (hosts, approvals, events, artifacts) lives under `~/.coxswain/` with file locking. Design: `docs/specs/2026-11-07-coxswain-design.md` (§4.0–4.5, §4.7, §6, §9 M0).

**Tech Stack:** Go 1.26 · cobra · modelcontextprotocol/go-sdk v1.8.0 · x/crypto/ssh + skeema/knownhosts · kevinburke/ssh_config · mvdan.cc/sh/v3 (command risk parsing) · GoReleaser v2 + GitHub Actions + Homebrew cask.

// Package action defines the unit every Coxswain capability is built from.
// An Action is registered once and exposed through every surface (CLI, MCP).
package action

import (
	"context"
	"encoding/json"
	"fmt"
	"regexp"
	"sort"
)

// Risk is how much damage an invocation can do. Higher is riskier.
type Risk int

const (
	Read Risk = iota
	Write
	Destructive
)

func (r Risk) String() string {
	switch r {
	case Read:
		return "read"
	case Write:
		return "write"
	default:
		return "destructive"
	}
}

func (r Risk) MarshalText() ([]byte, error) { return []byte(r.String()), nil }

// ActorKind tells humans and agents apart; policy treats them differently.
type ActorKind string

const (
	Human ActorKind = "human"
	Agent ActorKind = "agent"
)

// Actor is who asked for an invocation.
type Actor struct {
	Kind    ActorKind `json:"kind"`
	Name    string    `json:"name"`
	Session string    `json:"session,omitempty"`
}

func (a Actor) String() string { return string(a.Kind) + ":" + a.Name }

// Target is an object an invocation affects. Tags drive policy (env=prod).
type Target struct {
	Kind string            `json:"kind"`
	ID   string            `json:"id"`
	Tags map[string]string `json:"tags,omitempty"`
}

// Assessment is what an Action reports about one concrete invocation
// before it runs: how risky it is, what it touches, and what to show
// a human who must approve it.
type Assessment struct {
	Risk    Risk
	Targets []Target
	Preview string
}

// Action is one capability.
type Action struct {
	// ID is dotted, e.g. "ssh.exec". It becomes the CLI path (cox ssh exec)
	// and the MCP tool name (ssh_exec).
	ID          string
	Summary     string // one line, for humans
	Description string // for the LLM: when to use it, what not to do
	// Input is a JSON Schema object describing the arguments.
	Input map[string]any
	// Positional lists properties that the CLI accepts as positional
	// arguments, in order.
	Positional []string
	// RestArgs makes the last Positional (a string) collect all remaining
	// arguments joined by spaces, e.g. `cox ssh exec web df -h`. Flags must
	// then come before the positionals.
	RestArgs bool
	Assess   func(ctx context.Context, args json.RawMessage) (Assessment, error)
	Run      func(ctx context.Context, args json.RawMessage) (any, error)
}

var idPattern = regexp.MustCompile(`^[a-z][a-z0-9]*(\.[a-z][a-z0-9_]*)+$`)

// Registry holds all registered Actions.
type Registry struct {
	actions map[string]*Action
}

func NewRegistry() *Registry { return &Registry{actions: map[string]*Action{}} }

// Register adds an Action. It panics on programmer errors (bad ID,
// duplicate, missing schema or functions) so they surface at startup.
func (r *Registry) Register(a *Action) {
	if !idPattern.MatchString(a.ID) {
		panic(fmt.Sprintf("action: invalid id %q", a.ID))
	}
	if _, dup := r.actions[a.ID]; dup {
		panic(fmt.Sprintf("action: duplicate id %q", a.ID))
	}
	if a.Input == nil || a.Input["type"] != "object" {
		panic(fmt.Sprintf("action %q: Input must be a JSON Schema with type object", a.ID))
	}
	if a.Assess == nil || a.Run == nil {
		panic(fmt.Sprintf("action %q: Assess and Run are required", a.ID))
	}
	r.actions[a.ID] = a
}

func (r *Registry) Get(id string) (*Action, bool) {
	a, ok := r.actions[id]
	return a, ok
}

// List returns all Actions sorted by ID.
func (r *Registry) List() []*Action {
	out := make([]*Action, 0, len(r.actions))
	for _, a := range r.actions {
		out = append(out, a)
	}
	sort.Slice(out, func(i, j int) bool { return out[i].ID < out[j].ID })
	return out
}

// Decode unmarshals args into v, treating empty args as {}.
func Decode(args json.RawMessage, v any) error {
	if len(args) == 0 {
		args = json.RawMessage("{}")
	}
	if err := json.Unmarshal(args, v); err != nil {
		return fmt.Errorf("invalid arguments: %w", err)
	}
	return nil
}

type actorKey struct{}

// WithActor records the invoking actor in ctx; the engine does this
// before calling Run so Actions can tailor output (e.g. shaping for agents).
func WithActor(ctx context.Context, a Actor) context.Context {
	return context.WithValue(ctx, actorKey{}, a)
}

// ActorFrom returns the actor recorded by WithActor.
func ActorFrom(ctx context.Context) (Actor, bool) {
	a, ok := ctx.Value(actorKey{}).(Actor)
	return a, ok
}
```

// Package eventlog is the append-only audit trail: one JSON object per
// line, one file per day, under <home>/events/.
package eventlog

import (
	"bufio"
	"encoding/json"
	"errors"
	"os"
	"path/filepath"
	"sync"
	"time"

	"github.com/hua-ri/coxswain/internal/action"
)

// Event types.
const (
	ActionRequested = "action.requested"
	ActionFinished  = "action.finished"
	ActionFailed    = "action.failed"
	ApprovalDecided = "approval.decided"
)

type Event struct {
	Time       time.Time       `json:"time"`
	Type       string          `json:"type"`
	Actor      *action.Actor   `json:"actor,omitempty"`
	Action     string          `json:"action,omitempty"`
	Args       json.RawMessage `json:"args,omitempty"`
	Risk       string          `json:"risk,omitempty"`
	Targets    []action.Target `json:"targets,omitempty"`
	Decision   string          `json:"decision,omitempty"`
	ApprovalID string          `json:"approval_id,omitempty"`
	DurationMs int64           `json:"duration_ms,omitempty"`
	Error      string          `json:"error,omitempty"`
}

type Log struct {
	dir string
	mu  sync.Mutex
	Now func() time.Time
}

func Open(dir string) *Log { return &Log{dir: dir, Now: time.Now} }

func (l *Log) file(day time.Time) string {
	return filepath.Join(l.dir, day.Format("2006-01-02")+".jsonl")
}

// Append writes one event. Several processes may append to the same
// file; each event is a single write on an O_APPEND descriptor.
func (l *Log) Append(ev Event) error {
	l.mu.Lock()
	defer l.mu.Unlock()
	if ev.Time.IsZero() {
		ev.Time = l.Now()
	}
	line, err := json.Marshal(ev)
	if err != nil {
		return err
	}
	if err := os.MkdirAll(l.dir, 0o700); err != nil {
		return err
	}
	f, err := os.OpenFile(l.file(ev.Time), os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0o600)
	if err != nil {
		return err
	}
	defer f.Close()
	_, err = f.Write(append(line, '\n'))
	return err
}

// Read returns all events recorded on the given day.
func (l *Log) Read(day time.Time) ([]Event, error) {
	f, err := os.Open(l.file(day))
	if errors.Is(err, os.ErrNotExist) {
		return nil, nil
	}
	if err != nil {
		return nil, err
	}
	defer f.Close()
	var out []Event
	sc := bufio.NewScanner(f)
	sc.Buffer(make([]byte, 0, 64*1024), 16*1024*1024)
	for sc.Scan() {
		var ev Event
		if err := json.Unmarshal(sc.Bytes(), &ev); err != nil {
			return nil, err
		}
		out = append(out, ev)
	}
	return out, sc.Err()
}
```

// Package approval stores pending approvals on disk so that the process
// that asked (e.g. `cox mcp` under an agent) and the process that decides
// (`cox approve`, a dialog, later the desktop) can be different processes.
package approval

import (
	"crypto/rand"
	"crypto/sha256"
	"encoding/hex"
	"encoding/json"
	"errors"
	"fmt"
	"os"
	"path/filepath"
	"regexp"
	"sort"
	"strings"
	"syscall"
	"time"

	"github.com/hua-ri/coxswain/internal/action"
)

type Status string

const (
	Pending  Status = "pending"
	Approved Status = "approved"
	Denied   Status = "denied"
	Consumed Status = "consumed"
	Expired  Status = "expired"
)

type Approval struct {
	ID        string          `json:"id"`
	ActionID  string          `json:"action"`
	Args      json.RawMessage `json:"args"`
	ArgsHash  string          `json:"args_hash"`
	Actor     action.Actor    `json:"actor"`
	Risk      string          `json:"risk"`
	Targets   []action.Target `json:"targets,omitempty"`
	Preview   string          `json:"preview"`
	Status    Status          `json:"status"`
	CreatedAt time.Time       `json:"created_at"`
	ExpiresAt time.Time       `json:"expires_at"`
	DecidedAt *time.Time      `json:"decided_at,omitempty"`
}

var (
	ErrNotFound   = errors.New("approval not found")
	ErrNotPending = errors.New("approval is not pending")
	idPattern     = regexp.MustCompile(`^ap_[0-9a-f]{12}$`)
)

type Store struct {
	dir string
	ttl time.Duration
	Now func() time.Time
}

func NewStore(dir string, ttl time.Duration) *Store {
	return &Store{dir: dir, ttl: ttl, Now: time.Now}
}

// Hash binds an approval to one exact action and argument set.
func Hash(actionID string, args json.RawMessage) (string, error) {
	var v any
	if len(args) == 0 {
		args = json.RawMessage("{}")
	}
	if err := json.Unmarshal(args, &v); err != nil {
		return "", err
	}
	canon, err := json.Marshal(v) // map keys are sorted by encoding/json
	if err != nil {
		return "", err
	}
	sum := sha256.Sum256(append([]byte(actionID+"\x00"), canon...))
	return hex.EncodeToString(sum[:]), nil
}

// Create stores a new pending approval and fills in ID, hash and times.
func (s *Store) Create(ap Approval) (Approval, error) {
	h, err := Hash(ap.ActionID, ap.Args)
	if err != nil {
		return Approval{}, err
	}
	var b [6]byte
	if _, err := rand.Read(b[:]); err != nil {
		return Approval{}, err
	}
	now := s.Now()
	ap.ID = "ap_" + hex.EncodeToString(b[:])
	ap.ArgsHash = h
	ap.Status = Pending
	ap.CreatedAt = now
	ap.ExpiresAt = now.Add(s.ttl)
	return ap, s.withLock(func() error { return s.write(ap) })
}

// Get returns an approval; a pending one past its deadline reads as Expired.
func (s *Store) Get(id string) (Approval, error) {
	var ap Approval
	err := s.withLock(func() (err error) { ap, err = s.read(id); return })
	return ap, err
}

// List returns all approvals, oldest first.
func (s *Store) List() ([]Approval, error) {
	var out []Approval
	err := s.withLock(func() error {
		entries, err := os.ReadDir(s.dir)
		if errors.Is(err, os.ErrNotExist) {
			return nil
		}
		if err != nil {
			return err
		}
		for _, e := range entries {
			id, ok := strings.CutSuffix(e.Name(), ".json")
			if !ok || !idPattern.MatchString(id) {
				continue
			}
			ap, err := s.read(id)
			if err != nil {
				return err
			}
			out = append(out, ap)
		}
		return nil
	})
	sort.Slice(out, func(i, j int) bool { return out[i].CreatedAt.Before(out[j].CreatedAt) })
	return out, err
}

// Decide approves or denies a pending approval.
func (s *Store) Decide(id string, approve bool) (Approval, error) {
	return s.transition(id, Pending, map[bool]Status{true: Approved, false: Denied}[approve])
}

// Consume marks an approved approval as used. It succeeds at most once,
// so one approval can never run twice.
func (s *Store) Consume(id string) (Approval, error) {
	ap, err := s.transition(id, Approved, Consumed)
	if err != nil {
		return ap, err
	}
	h, err := Hash(ap.ActionID, ap.Args)
	if err != nil {
		return ap, err
	}
	if h != ap.ArgsHash {
		return ap, fmt.Errorf("approval %s: arguments changed after approval", id)
	}
	return ap, nil
}

func (s *Store) transition(id string, from, to Status) (Approval, error) {
	var ap Approval
	err := s.withLock(func() error {
		var err error
		ap, err = s.read(id)
		if err != nil {
			return err
		}
		if ap.Status != from {
			if from == Pending {
				return fmt.Errorf("%w (status: %s)", ErrNotPending, ap.Status)
			}
			return fmt.Errorf("approval %s is %s, not %s", id, ap.Status, from)
		}
		now := s.Now()
		ap.Status = to
		if from == Pending {
			ap.DecidedAt = &now
		}
		return s.write(ap)
	})
	return ap, err
}

func (s *Store) path(id string) string { return filepath.Join(s.dir, id+".json") }

func (s *Store) read(id string) (Approval, error) {
	if !idPattern.MatchString(id) {
		return Approval{}, fmt.Errorf("%w: %q", ErrNotFound, id)
	}
	b, err := os.ReadFile(s.path(id))
	if errors.Is(err, os.ErrNotExist) {
		return Approval{}, fmt.Errorf("%w: %s", ErrNotFound, id)
	}
	if err != nil {
		return Approval{}, err
	}
	var ap Approval
	if err := json.Unmarshal(b, &ap); err != nil {
		return Approval{}, err
	}
	if ap.Status == Pending && s.Now().After(ap.ExpiresAt) {
		ap.Status = Expired
	}
	return ap, nil
}

func (s *Store) write(ap Approval) error {
	b, err := json.MarshalIndent(ap, "", "  ")
	if err != nil {
		return err
	}
	tmp := s.path(ap.ID) + ".tmp"
	if err := os.WriteFile(tmp, b, 0o600); err != nil {
		return err
	}
	return os.Rename(tmp, s.path(ap.ID))
}

// withLock serialises store access across processes with flock(2).
func (s *Store) withLock(fn func() error) error {
	if err := os.MkdirAll(s.dir, 0o700); err != nil {
		return err
	}
	f, err := os.OpenFile(filepath.Join(s.dir, ".lock"), os.O_CREATE|os.O_RDWR, 0o600)
	if err != nil {
		return err
	}
	defer f.Close()
	if err := syscall.Flock(int(f.Fd()), syscall.LOCK_EX); err != nil {
		return err
	}
	defer syscall.Flock(int(f.Fd()), syscall.LOCK_UN)
	return fn()
}

func set(xs ...string) map[string]bool {
	m := make(map[string]bool, len(xs))
	for _, x := range xs {
		m[x] = true
	}
	return m

// ClassifyCommand rates a shell command line. Anything it cannot fully
// understand is rated Destructive so that it is always confirmed.
func ClassifyCommand(cmd string) action.Risk {
	f, err := syntax.NewParser().Parse(strings.NewReader(cmd), "")
	if err != nil {
		return action.Destructive
	}
	risk := action.Read
	raise := func(r action.Risk) {
		if r > risk {
			risk = r
		}
	}
	syntax.Walk(f, func(n syntax.Node) bool {
		switch n := n.(type) {
		case *syntax.FuncDecl: // e.g. fork bombs
			raise(action.Destructive)
		case *syntax.Redirect:
			raise(classifyRedirect(n))
		case *syntax.CallExpr:
			raise(classifyCall(n.Args))
		case *syntax.DeclClause, *syntax.TestClause, *syntax.ArithmCmd, *syntax.LetClause:
			// harmless on their own; nested calls are walked separately
		}
		return true
	})
	return risk
}

func classifyRedirect(r *syntax.Redirect) action.Risk {
	switch r.Op {
	case syntax.RdrOut, syntax.AppOut, syntax.RdrAll, syntax.AppAll, syntax.RdrClob, syntax.RdrInOut:
		target, ok := literal(r.Word)
		if !ok {
			return action.Destructive
		}
		if target == "/dev/null" || target == "/dev/stdout" || target == "/dev/stderr" {
			return action.Read
		}
		if isProtected(target) {
			return action.Destructive
		}
		return action.Write
	}
	return action.Read
}

func classifyCall(words []*syntax.Word) action.Risk {
	if len(words) == 0 { // pure assignment like FOO=bar
		return action.Read
	}
	args := make([]string, 0, len(words))
	for i, w := range words {
		s, ok := literal(w)
		if !ok {
			if i == 0 {
				return action.Destructive // command name computed at runtime
			}
			s = "\x00dynamic" // dynamic argument: keep position, cannot be inspected
		}
		args = append(args, s)
	}
	return classifyArgs(args, 0)
}

func classifyArgs(args []string, depth int) action.Risk {
	if depth > 4 {
		return action.Destructive
	}
	args = stripWrapper(args)
	if len(args) == 0 {
		return action.Read
	}
	name := path.Base(args[0])
	rest := args[1:]

	switch {
	case destructiveCmd[name], strings.HasPrefix(name, "mkfs."):
		return action.Destructive
	case name == "sh" || name == "bash" || name == "zsh" || name == "dash":
		for i, a := range rest {
			if a == "-c" && i+1 < len(rest) {
				if strings.Contains(rest[i+1], "\x00dynamic") {
					return action.Destructive
				}
				return ClassifyCommand(rest[i+1])
			}
		}
		return action.Destructive // a shell reading a script or stdin
	case name == "rm":
		for _, a := range rest {
			if a == "--recursive" || (strings.HasPrefix(a, "-") && !strings.HasPrefix(a, "--") && strings.ContainsAny(a, "rR")) {
				return action.Destructive
			}
		}
		return action.Write
	case name == "dd":
		for _, a := range rest {
			if strings.HasPrefix(a, "of=") && a != "of=/dev/null" {
				return action.Destructive
			}
		}
		return action.Read
	case name == "find":
		for _, a := range rest {
			switch a {
			case "-delete":
				return action.Destructive
			case "-exec", "-execdir", "-ok", "-okdir", "-fprint", "-fprintf", "-fls":
				return action.Write
			}
		}
		return action.Read
	case name == "sed":
		for _, a := range rest {
			if a == "--in-place" || (strings.HasPrefix(a, "-") && !strings.HasPrefix(a, "--") && strings.Contains(a, "i")) {
				return writeTargets(rest)
			}
		}
		return action.Read
	case name == "tee":
		return writeTargets(rest)
	case name == "awk":
		for _, a := range rest {
			if strings.Contains(a, "system(") || strings.Contains(a, "| getline") || strings.Contains(a, ">") {
				return action.Write
			}
		}
		return action.Read
	case name == "journalctl":
		for _, a := range rest {
			if strings.HasPrefix(a, "--vacuum") || a == "--rotate" || a == "--flush" {
				return action.Write
			}
		}
		return action.Read
	case name == "cp" || name == "mv" || name == "install" || name == "rsync" || name == "ln" || name == "chmod" || name == "chown":
		return writeTargets(rest)
	case readOnly[name]:
		return action.Read
	}
	if subs, ok := readOnlySub[name]; ok {
		for _, a := range rest {
			if subs[a] {
				return action.Read
			}
			if !strings.HasPrefix(a, "-") {
				break // first non-flag word is the subcommand
			}
		}
		return action.Write
	}
	return action.Write
}

// writeTargets rates a command that writes to the paths among its args.
func writeTargets(args []string) action.Risk {
	for _, a := range args {
		if isProtected(a) {
			return action.Destructive
		}
	}
	return action.Write
}

func isProtected(p string) bool {
	if strings.HasPrefix(p, "$HOME/") {
		p = "~/" + p[len("$HOME/"):]
	}
	for _, pre := range protectedPrefixes {
		if strings.HasPrefix(p, pre) {
			return true
		}
	}
	return p == "/"
}

// stripWrapper removes leading wrapper commands (sudo -u x, env A=b,
// timeout 5, xargs -0 …) and returns the wrapped command.
func stripWrapper(args []string) []string {
	for len(args) > 0 && wrappers[path.Base(args[0])] {
		w := path.Base(args[0])
		args = args[1:]
		for len(args) > 0 {
			a := args[0]
			switch {
			case w == "env" && strings.Contains(a, "=") && !strings.HasPrefix(a, "-"):
				args = args[1:]
			case strings.HasPrefix(a, "-"):
				args = args[1:]
				if takesValue(w, a) && len(args) > 0 {
					args = args[1:]
				}
			case w == "timeout" && len(a) > 0 && a[0] >= '0' && a[0] <= '9':
				args = args[1:]
			default:
				goto next
			}
		}
	next:
	}
	return args
}

func takesValue(wrapper, flag string) bool {
	switch wrapper {
	case "sudo":
		return flag == "-u" || flag == "-g" || flag == "-C" || flag == "-h" || flag == "-p" || flag == "-U"
	case "env":
		return flag == "-u" || flag == "-C"
	case "nice", "ionice":
		return flag == "-n" || flag == "-c"
	case "timeout":
		return flag == "-s" || flag == "-k" || flag == "--signal" || flag == "--kill-after"
	case "xargs":
		return flag == "-n" || flag == "-I" || flag == "-P" || flag == "-L" || flag == "-d" || flag == "-s" || flag == "-E"
	case "stdbuf":
		return flag == "-i" || flag == "-o" || flag == "-e"
	}
	return false
}

// literal returns the word's value if it contains no expansions.
func literal(w *syntax.Word) (string, bool) {
	var sb strings.Builder
	for _, p := range w.Parts {
		switch p := p.(type) {
		case *syntax.Lit:
			sb.WriteString(p.Value)
		case *syntax.SglQuoted:
			sb.WriteString(p.Value)
		case *syntax.DblQuoted:
			for _, q := range p.Parts {
				lit, ok := q.(*syntax.Lit)
				if !ok {
					return "", false
				}
				sb.WriteString(lit.Value)
			}
		case *syntax.ParamExp:
			// allow $HOME only, so ~/.ssh-style protection still applies
			if p.Param != nil && p.Param.Value == "HOME" && p.Exp == nil && p.Repl == nil && p.Index == nil && p.Slice == nil {
				sb.WriteString("$HOME")
				continue
			}
			return "", false
		default:
			return "", false
		}
	}
	return sb.String(), true
}

package policy

import "github.com/hua-ri/coxswain/internal/action"

// Mode is how much an agent may do on a target without asking.
type Mode string

const (
	Always   Mode = "always"   // every agent write is confirmed
	Balanced Mode = "balanced" // only destructive agent actions are confirmed
	Auto     Mode = "auto"     // nothing is confirmed (sandboxes only)
)

var strictness = map[Mode]int{Auto: 0, Balanced: 1, Always: 2}

// Decision is the outcome of a policy check.
type Decision string

const (
	Allow Decision = "allow"
	Ask   Decision = "ask"
)

// ModeFor returns the strictest mode among the targets. A target's mode
// is its ai_policy tag if set, else Always for env=prod, else Balanced.
func ModeFor(targets []action.Target) Mode {
	if len(targets) == 0 {
		return Balanced
	}
	mode := Auto
	for _, t := range targets {
		if m := targetMode(t); strictness[m] > strictness[mode] {
			mode = m
		}
	}
	return mode
}

func targetMode(t action.Target) Mode {
	if m := Mode(t.Tags["ai_policy"]); m == Always || m == Balanced || m == Auto {
		return m
	}
	if t.Tags["env"] == "prod" {
		return Always
	}
	return Balanced
}

// Decide applies the policy:
//   - reads always run;
//   - a human's writes run, a human's destructive actions are confirmed;
//   - an agent's writes follow the target mode.
func Decide(actor action.Actor, as action.Assessment) Decision {
	if as.Risk == action.Read {
		return Allow
	}
	if actor.Kind == action.Human {
		if as.Risk == action.Destructive {
			return Ask
		}
		return Allow
	}
	switch ModeFor(as.Targets) {
	case Auto:
		return Allow
	case Balanced:
		if as.Risk == action.Destructive {
			return Ask
		}
		return Allow
	default:
		return Ask
	}
}

// Package shaper keeps tool output small enough for an LLM context.
// Oversized output is saved as an artifact and replaced by its head and
// tail plus an artifact id that can be read on demand.
package shaper

import (
	"crypto/rand"
	"encoding/hex"
	"fmt"
	"os"
	"path/filepath"
	"regexp"
	"strings"
)

type Limits struct {
	MaxBytes int
	MaxLines int
}

var Default = Limits{MaxBytes: 8 * 1024, MaxLines: 200}

type Shaped struct {
	Text       string `json:"text"`
	Truncated  bool   `json:"truncated,omitempty"`
	TotalLines int    `json:"total_lines"`
	TotalBytes int    `json:"total_bytes"`
	ArtifactID string `json:"artifact_id,omitempty"`
}

type Artifacts struct{ dir string }

func NewArtifacts(dir string) *Artifacts { return &Artifacts{dir: dir} }

var idPattern = regexp.MustCompile(`^art_[0-9a-f]{12}$`)

// Shape returns s unchanged if it fits the limits; otherwise it stores s
// as an artifact and returns its head and tail.
func (a *Artifacts) Shape(s string, lim Limits) (Shaped, error) {
	lines := splitLines(s)
	out := Shaped{Text: s, TotalLines: len(lines), TotalBytes: len(s)}
	if len(s) <= lim.MaxBytes && len(lines) <= lim.MaxLines {
		return out, nil
	}
	id, err := a.save(s)
	if err != nil {
		return Shaped{}, err
	}
	keep := lim.MaxLines / 2
	headN := min(keep, len(lines))
	head := clip(lines[:headN], lim.MaxBytes/2)
	tail := clipTail(lines[max(len(lines)-keep, headN):], lim.MaxBytes/2)
	omitted := len(lines) - len(head) - len(tail)
	out.Text = strings.Join(head, "\n") +
		fmt.Sprintf("\n… %d lines omitted; full output is artifact %s (read with cox_artifact_read) …\n", omitted, id) +
		strings.Join(tail, "\n")
	out.Truncated = true
	out.ArtifactID = id
	return out, nil
}

// Read returns lines [start, end] (1-based, inclusive; 0 means open) of an
// artifact, optionally only those matching grep. At most 500 lines.
func (a *Artifacts) Read(id, grep string, start, end int) (string, error) {
	if !idPattern.MatchString(id) {
		return "", fmt.Errorf("invalid artifact id %q", id)
	}
	b, err := os.ReadFile(filepath.Join(a.dir, id+".txt"))
	if err != nil {
		return "", fmt.Errorf("artifact %s: %w", id, err)
	}
	var re *regexp.Regexp
	if grep != "" {
		if re, err = regexp.Compile(grep); err != nil {
			return "", fmt.Errorf("invalid grep pattern: %w", err)
		}
	}
	lines := splitLines(string(b))
	if start < 1 {
		start = 1
	}
	if end < 1 || end > len(lines) {
		end = len(lines)
	}
	var out []string
	for i := start; i <= end && len(out) < 500; i++ {
		if re == nil || re.MatchString(lines[i-1]) {
			out = append(out, fmt.Sprintf("%d: %s", i, lines[i-1]))
		}
	}
	return strings.Join(out, "\n"), nil
}

func (a *Artifacts) save(s string) (string, error) {
	var b [6]byte
	if _, err := rand.Read(b[:]); err != nil {
		return "", err
	}
	id := "art_" + hex.EncodeToString(b[:])
	if err := os.MkdirAll(a.dir, 0o700); err != nil {
		return "", err
	}
	return id, os.WriteFile(filepath.Join(a.dir, id+".txt"), []byte(s), 0o600)
}

func splitLines(s string) []string {
	if s == "" {
		return nil
	}
	return strings.Split(strings.TrimSuffix(s, "\n"), "\n")
}

// clip keeps leading lines until maxBytes is reached. A first line that
// alone exceeds maxBytes is cut.
func clip(lines []string, maxBytes int) []string {
	n := 0
	for i, l := range lines {
		n += len(l) + 1
		if n > maxBytes {
			if i == 0 {
				return []string{l[:maxBytes] + "…"}
			}
			return lines[:i]
		}
	}
	return lines
}

// clipTail keeps trailing lines until maxBytes is reached. A last line
// that alone exceeds maxBytes is cut.
func clipTail(lines []string, maxBytes int) []string {
	n := 0
	for i := len(lines) - 1; i >= 0; i-- {
		n += len(lines[i]) + 1
		if n > maxBytes {
			if i == len(lines)-1 {
				l := lines[i]
				return []string{"…" + l[len(l)-maxBytes:]}
			}
			return lines[i+1:]
		}
	}
	return lines
}

// Package engine runs Actions: assess → policy → (approval) → run → audit.
// Every surface (CLI, MCP) goes through Engine; none calls Action.Run directly.
package engine

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"time"

	"github.com/hua-ri/coxswain/internal/action"
	"github.com/hua-ri/coxswain/internal/approval"
	"github.com/hua-ri/coxswain/internal/eventlog"
	"github.com/hua-ri/coxswain/internal/policy"
)

// Outcome statuses.
const (
	StatusOK               = "ok"
	StatusError            = "error"
	StatusApprovalRequired = "approval_required"
	StatusApprovalPending  = "approval_pending"
	StatusDenied           = "denied"
)

// DeniedHint is returned to agents whose action was refused, so that
// they do not try to reach the same result another way.
const DeniedHint = "The action was rejected and will not be executed. Do not pursue the same outcome " +
	"through a workaround, indirect execution, or policy circumvention. Continue only with a " +
	"materially safer alternative; otherwise stop and ask the user."

type Outcome struct {
	Status     string `json:"status"`
	Result     any    `json:"result,omitempty"`
	Error      string `json:"error,omitempty"`
	ApprovalID string `json:"approval_id,omitempty"`
	Risk       string `json:"risk,omitempty"`
	Preview    string `json:"preview,omitempty"`
	Hint       string `json:"hint,omitempty"`
}

// Verdict is a human decision on an approval.
type Verdict int

const (
	Undecided Verdict = iota
	Approved
	Denied
)

// Confirmer asks a human about a pending approval right away (terminal
// prompt, macOS dialog). It returns Undecided if nobody answered.
type Confirmer func(ctx context.Context, ap approval.Approval) Verdict

type Engine struct {
	Registry  *action.Registry
	Approvals *approval.Store
	Events    *eventlog.Log
}

// Invoke runs one Action for an actor. If policy asks for approval, an
// approval record is created and confirm (may be nil) is consulted.
func (e *Engine) Invoke(ctx context.Context, actor action.Actor, id string, args json.RawMessage, confirm Confirmer) Outcome {
	a, ok := e.Registry.Get(id)
	if !ok {
		return Outcome{Status: StatusError, Error: fmt.Sprintf("unknown action %q", id)}
	}
	if len(args) == 0 {
		args = json.RawMessage("{}")
	}
	as, err := a.Assess(ctx, args)
	if err != nil {
		return Outcome{Status: StatusError, Error: err.Error()}
	}
	dec := policy.Decide(actor, as)
	if err := e.Events.Append(eventlog.Event{
		Type: eventlog.ActionRequested, Actor: &actor, Action: id, Args: args,
		Risk: as.Risk.String(), Targets: as.Targets, Decision: string(dec),
	}); err != nil {
		return Outcome{Status: StatusError, Error: "audit log unavailable, refusing to run: " + err.Error()}
	}
	if dec == policy.Allow {
		return e.run(ctx, actor, a, args, "")
	}

	ap, err := e.Approvals.Create(approval.Approval{
		ActionID: id, Args: args, Actor: actor, Risk: as.Risk.String(),
		Targets: as.Targets, Preview: as.Preview,
	})
	if err != nil {
		return Outcome{Status: StatusError, Error: err.Error()}
	}
	if confirm != nil {
		switch confirm(ctx, ap) {
		case Approved:
			if _, err := e.Decide(ap.ID, true, actor); err != nil {
				return Outcome{Status: StatusError, Error: err.Error()}
			}
			return e.RunApproved(ctx, actor, ap.ID)
		case Denied:
			if _, err := e.Decide(ap.ID, false, actor); err != nil {
				return Outcome{Status: StatusError, Error: err.Error()}
			}
			return Outcome{Status: StatusDenied, ApprovalID: ap.ID, Hint: DeniedHint}
		}
	}
	return Outcome{
		Status: StatusApprovalRequired, ApprovalID: ap.ID, Risk: ap.Risk, Preview: ap.Preview,
		Hint: fmt.Sprintf("This action needs the user's approval. Tell the user what you want to do and why; "+
			"they approve it with `cox approve %s`. Then wait for the decision.", ap.ID),
	}
}

// Decide records a human decision on a pending approval.
func (e *Engine) Decide(id string, approve bool, by action.Actor) (approval.Approval, error) {
	ap, err := e.Approvals.Decide(id, approve)
	if err != nil {
		return ap, err
	}
	dec := "denied"
	if approve {
		dec = "approved"
	}
	return ap, e.Events.Append(eventlog.Event{
		Type: eventlog.ApprovalDecided, Actor: &by, Action: ap.ActionID, ApprovalID: id, Decision: dec,
	})
}

// RunApproved runs the exact invocation stored in an approved approval.
// It reports approval_pending if the user has not decided yet.
func (e *Engine) RunApproved(ctx context.Context, actor action.Actor, id string) Outcome {
	ap, err := e.Approvals.Get(id)
	if err != nil {
		return Outcome{Status: StatusError, Error: err.Error()}
	}
	if ap.Actor.Kind != actor.Kind || ap.Actor.Name != actor.Name {
		return Outcome{Status: StatusError, Error: fmt.Sprintf("approval %s belongs to %s", id, ap.Actor)}
	}
	switch ap.Status {
	case approval.Pending:
		return Outcome{Status: StatusApprovalPending, ApprovalID: id, Preview: ap.Preview}
	case approval.Denied:
		return Outcome{Status: StatusDenied, ApprovalID: id, Hint: DeniedHint}
	case approval.Approved:
	default:
		return Outcome{Status: StatusError, ApprovalID: id, Error: fmt.Sprintf("approval %s is %s", id, ap.Status)}
	}
	ap, err = e.Approvals.Consume(id)
	if err != nil {
		return Outcome{Status: StatusError, Error: err.Error()}
	}
	a, ok := e.Registry.Get(ap.ActionID)
	if !ok {
		return Outcome{Status: StatusError, Error: fmt.Sprintf("unknown action %q", ap.ActionID)}
	}
	return e.run(ctx, actor, a, ap.Args, id)
}

// Wait polls an approval until it is decided, ctx ends, or timeout passes.
func (e *Engine) Wait(ctx context.Context, id string, timeout, every time.Duration) (approval.Status, error) {
	deadline := time.Now().Add(timeout)
	for {
		ap, err := e.Approvals.Get(id)
		if err != nil {
			return "", err
		}
		if ap.Status != approval.Pending || time.Now().After(deadline) {
			return ap.Status, nil
		}
		select {
		case <-ctx.Done():
			return ap.Status, ctx.Err()
		case <-time.After(every):
		}
	}
}

func (e *Engine) run(ctx context.Context, actor action.Actor, a *action.Action, args json.RawMessage, approvalID string) Outcome {
	start := time.Now()
	res, err := a.Run(action.WithActor(ctx, actor), args)
	ev := eventlog.Event{
		Type: eventlog.ActionFinished, Actor: &actor, Action: a.ID, ApprovalID: approvalID,
		DurationMs: time.Since(start).Milliseconds(),
	}
	if err != nil {
		ev.Type, ev.Error = eventlog.ActionFailed, err.Error()
	}
	logErr := e.Events.Append(ev)
	if err != nil {
		return Outcome{Status: StatusError, Error: err.Error(), ApprovalID: approvalID}
	}
	out := Outcome{Status: StatusOK, Result: res, ApprovalID: approvalID}
	if logErr != nil {
		out.Hint = "warning: audit log write failed: " + logErr.Error()
	}
	return out
}

// ErrStatus lets surfaces map an Outcome to a Go error.
func (o Outcome) Err() error {
	switch o.Status {
	case StatusOK:
		return nil
	case StatusError:
		return errors.New(o.Error)
	default:
		return errors.New(o.Status)
	}
}

// (Claude Code, Codex, Kimi) running it through its shell tool.
package actor

import (
	"os"
	"strings"

	"github.com/hua-ri/coxswain/internal/action"
	"golang.org/x/sys/unix"
)

// agentNames maps a process name (as the kernel reports it, at most
// 16 bytes) to the agent it belongs to.
var agentNames = map[string]string{
	"claude": "claude-code",
	"codex":  "codex",
	"kimi":   "kimi",
}

// Detect returns an agent actor if COX_ACTOR names one or any ancestor
// process is a known agent; otherwise a human actor. COX_ACTOR can only
// make the caller an agent, never a human.
func Detect() action.Actor {
	if v := os.Getenv("COX_ACTOR"); v != "" {
		return action.Actor{Kind: action.Agent, Name: strings.TrimPrefix(v, "agent:")}
	}
	if name, ok := FromAncestors(os.Getppid(), parent); ok {
		return action.Actor{Kind: action.Agent, Name: name}
	}
	u := os.Getenv("USER")
	if u == "" {
		u = "user"
	}
	return action.Actor{Kind: action.Human, Name: u}
}

// FromAncestors walks up from pid (at most 64 levels) and returns the
// agent name of the first ancestor that is a known agent.
func FromAncestors(pid int, lookup func(int) (ppid int, comm string, ok bool)) (string, bool) {
	for i := 0; i < 64 && pid > 1; i++ {
		ppid, comm, ok := lookup(pid)
		if !ok {
			return "", false
		}
		if name, isAgent := agentNames[comm]; isAgent {
			return name, true
		}
		pid = ppid
	}
	return "", false
}

func parent(pid int) (int, string, bool) {
	kp, err := unix.SysctlKinfoProc("kern.proc.pid", pid)
	if err != nil {
		return 0, "", false
	}
	return int(kp.Eproc.Ppid), unix.ByteSliceToString(kp.Proc.P_comm[:]), true
}

	User          string            `json:"user,omitempty"`
	IdentityFiles []string          `json:"identity_files,omitempty"`

var ErrNotFound = errors.New("host not found")

// Store keeps hosts in one JSON file (mode 0600).
type Store struct {
	path string
	mu   sync.Mutex
}

func NewStore(path string) *Store { return &Store{path: path} }

func (s *Store) List() ([]Host, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	m, err := s.load()
	if err != nil {
		return nil, err
	}
	out := make([]Host, 0, len(m))
	for _, h := range m {
		out = append(out, h)
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Name < out[j].Name })
	return out, nil
}

func (s *Store) Get(name string) (Host, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	m, err := s.load()
	if err != nil {
		return Host{}, err
	}
	h, ok := m[name]
	if !ok {
		return Host{}, fmt.Errorf("%w: %s (list hosts with `cox ssh hosts list`)", ErrNotFound, name)
	}
	return h, nil
}

// Update loads the host map, lets fn change it, and saves it.
func (s *Store) Update(fn func(hosts map[string]Host) error) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	m, err := s.load()
	if err != nil {
		return err
	}
	if err := fn(m); err != nil {
		return err
	}
	return s.save(m)
}

// Merge adds imported hosts. Hosts that already exist get the imported
// connection fields but keep their tags and note.
func (s *Store) Merge(imported []Host) (added, updated int, err error) {
	err = s.Update(func(m map[string]Host) error {
		for _, h := range imported {
			if old, ok := m[h.Name]; ok {
				h.Tags, h.Note = old.Tags, old.Note
				updated++
			} else {
				added++
			}
			m[h.Name] = h
		}
		return nil
	})
	return
}

func (s *Store) load() (map[string]Host, error) {
	b, err := os.ReadFile(s.path)
	if errors.Is(err, os.ErrNotExist) {
		return map[string]Host{}, nil
	}
	if err != nil {
		return nil, err
	}
	var list []Host
	if err := json.Unmarshal(b, &list); err != nil {
		return nil, fmt.Errorf("%s: %w", s.path, err)
	}
	m := make(map[string]Host, len(list))
	for _, h := range list {
		m[h.Name] = h
	}
	return m, nil
}

func (s *Store) save(m map[string]Host) error {
	list := make([]Host, 0, len(m))
	for _, h := range m {
		list = append(list, h)
	}
	sort.Slice(list, func(i, j int) bool { return list[i].Name < list[j].Name })
	b, err := json.MarshalIndent(list, "", "  ")
	if err != nil {
		return err
	}
	if err := os.MkdirAll(filepath.Dir(s.path), 0o700); err != nil {
		return err
	}
	tmp := s.path + ".tmp"
	if err := os.WriteFile(tmp, b, 0o600); err != nil {
		return err
	}
	return os.Rename(tmp, s.path)
}

// ImportSSHConfig reads an OpenSSH client config and returns one Host for
// every concrete Host alias (patterns with *, ? or ! are skipped).
// Paths starting with ~ are expanded against home.
func ImportSSHConfig(r io.Reader, home string) ([]Host, error) {
	cfg, err := ssh_config.Decode(r)
	if err != nil {
		return nil, err
	}
	seen := map[string]bool{}
	var out []Host
	for _, h := range cfg.Hosts {
		for _, p := range h.Patterns {
			alias := p.String()
			if alias == "" || strings.ContainsAny(alias, "*?!") || seen[alias] {
				continue
			}
			seen[alias] = true
			host := Host{Name: alias, HostName: alias, Port: 22, Source: "ssh_config"}
			if v, _ := cfg.Get(alias, "HostName"); v != "" {
				host.HostName = strings.ReplaceAll(v, "%h", alias)
			}
			if v, _ := cfg.Get(alias, "Port"); v != "" {
				if n, err := strconv.Atoi(v); err == nil {
					host.Port = n
				}
			}
			host.User, _ = cfg.Get(alias, "User")
			host.ProxyJump, _ = cfg.Get(alias, "ProxyJump")
			if host.ProxyJump == "none" {
				host.ProxyJump = ""
			}
			files, _ := cfg.GetAll(alias, "IdentityFile")
			for _, f := range files {
				host.IdentityFiles = append(host.IdentityFiles, expandHome(f, home))
			}
			out = append(out, host)
		}
	}
	return out, nil
}

func expandHome(p, home string) string {
	if p == "~" {
		return home
	}
	if strings.HasPrefix(p, "~/") {
		return filepath.Join(home, p[2:])
	}
	return p
}

// Package sshtest runs a small SSH server for tests. It accepts one
// ed25519 client key, runs "exec" requests with /bin/sh on this machine,
// and forwards direct-tcpip channels (so it can act as a ProxyJump host).
package sshtest

import (
	"crypto/ed25519"
	"crypto/rand"
	"encoding/binary"
	"encoding/pem"
	"io"
	"net"
	"os"
	"os/exec"
	"path/filepath"
	"strconv"
	"sync"
	"testing"

	"github.com/skeema/knownhosts"
	"golang.org/x/crypto/ssh"
)

type Server struct {
	Addr       string // 127.0.0.1:port
	Host       string
	Port       int
	User       string
	KeyFile    string // client private key (OpenSSH PEM, unencrypted)
	KnownHosts string // known_hosts file containing this server's key
	Commands   chan string
}

// Start starts a server that lives until the test ends.
func Start(t *testing.T) *Server {
	t.Helper()
	dir := t.TempDir()
	_, hostPriv, _ := ed25519.GenerateKey(rand.Reader)
	hostSigner, err := ssh.NewSignerFromKey(hostPriv)
	if err != nil {
		t.Fatal(err)
	}
	clientPub, clientPriv, _ := ed25519.GenerateKey(rand.Reader)
	block, err := ssh.MarshalPrivateKey(clientPriv, "")
	if err != nil {
		t.Fatal(err)
	}
	keyFile := filepath.Join(dir, "id_ed25519")
	if err := os.WriteFile(keyFile, pem.EncodeToMemory(block), 0o600); err != nil {
		t.Fatal(err)
	}
	authorized, _ := ssh.NewPublicKey(clientPub)

	cfg := &ssh.ServerConfig{
		PublicKeyCallback: func(_ ssh.ConnMetadata, k ssh.PublicKey) (*ssh.Permissions, error) {
			if string(k.Marshal()) == string(authorized.Marshal()) {
				return nil, nil
			}
			return nil, io.EOF
		},
	}
	cfg.AddHostKey(hostSigner)

	ln, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		t.Fatal(err)
	}
	t.Cleanup(func() { ln.Close() })
	addr := ln.Addr().(*net.TCPAddr)
	s := &Server{
		Addr: addr.String(), Host: "127.0.0.1", Port: addr.Port, User: "tester",
		KeyFile: keyFile, KnownHosts: filepath.Join(dir, "known_hosts"),
		Commands: make(chan string, 100),
	}
	line := knownhosts.Line([]string{knownhosts.Normalize(s.Addr)}, hostSigner.PublicKey())
	if err := os.WriteFile(s.KnownHosts, []byte(line+"\n"), 0o600); err != nil {
		t.Fatal(err)
	}
	go func() {
		for {
			c, err := ln.Accept()
			if err != nil {
				return
			}
			go s.serve(c, cfg)
		}
	}()
	return s
}

func (s *Server) serve(c net.Conn, cfg *ssh.ServerConfig) {
	_, chans, reqs, err := ssh.NewServerConn(c, cfg)
	if err != nil {
		c.Close()
		return
	}
	go ssh.DiscardRequests(reqs)
	for nc := range chans {
		switch nc.ChannelType() {
		case "session":
			go s.session(nc)
		case "direct-tcpip":
			go directTCPIP(nc)
		default:
			nc.Reject(ssh.UnknownChannelType, "unsupported")
		}
	}
}

func (s *Server) session(nc ssh.NewChannel) {
	ch, reqs, err := nc.Accept()
	if err != nil {
		return
	}
	defer ch.Close()
	var mu sync.Mutex
	var cmd *exec.Cmd
	for req := range reqs {
		switch req.Type {
		case "exec":
			var p struct{ Command string }
			ssh.Unmarshal(req.Payload, &p)
			req.Reply(true, nil)
			select {
			case s.Commands <- p.Command:
			default:
			}
			mu.Lock()
			cmd = exec.Command("/bin/sh", "-c", p.Command)
			cmd.Stdout, cmd.Stderr = ch, ch.Stderr()
			mu.Unlock()
			code := 0
			if err := cmd.Run(); err != nil {
				code = 255
				if ee, ok := err.(*exec.ExitError); ok && ee.ExitCode() >= 0 {
					code = ee.ExitCode()
				}
			}
			status := make([]byte, 4)
			binary.BigEndian.PutUint32(status, uint32(code))
			ch.SendRequest("exit-status", false, status)
			return
		case "signal":
			mu.Lock()
			if cmd != nil && cmd.Process != nil {
				cmd.Process.Kill()
			}
			mu.Unlock()
		default:
			req.Reply(false, nil)
		}
	}
}

func directTCPIP(nc ssh.NewChannel) {
	var p struct {
		Host     string
		Port     uint32
		OrigHost string
		OrigPort uint32
	}
	if err := ssh.Unmarshal(nc.ExtraData(), &p); err != nil {
		nc.Reject(ssh.ConnectionFailed, err.Error())
		return
	}
	dst, err := net.Dial("tcp", net.JoinHostPort(p.Host, strconv.Itoa(int(p.Port))))
	if err != nil {
		nc.Reject(ssh.ConnectionFailed, err.Error())
		return
	}
	ch, reqs, err := nc.Accept()
	if err != nil {
		dst.Close()
		return
	}
	go ssh.DiscardRequests(reqs)
	go func() { io.Copy(ch, dst); ch.CloseWrite() }()
	io.Copy(dst, ch)
	dst.Close()
	ch.Close()
}

// ssh-agent and key files, strict known_hosts, ProxyJump chains.
package sshx

import (
	"bytes"
	"context"
	"errors"
	"fmt"
	"net"
	"os"
	"os/user"
	"strconv"
	"strings"
	"time"

	"github.com/hua-ri/coxswain/internal/inventory"

	"golang.org/x/crypto/ssh"

type Dialer struct {
	Hosts       *inventory.Store // resolves ProxyJump aliases
	KnownHosts  []string         // known_hosts files; missing files are skipped
	DefaultKeys []string         // tried when a host lists no IdentityFile
	AgentSocket string           // SSH_AUTH_SOCK; empty disables the agent
	Timeout     time.Duration
}

// Conn is a connection to a host plus the jump connections under it.
type Conn struct {
	*ssh.Client
	jumps []*ssh.Client
}

func (c *Conn) Close() error {
	err := c.Client.Close()
	for i := len(c.jumps) - 1; i >= 0; i-- {
		c.jumps[i].Close()
	}
	return err
}

// Dial connects to h, through h.ProxyJump if set.
func (d *Dialer) Dial(ctx context.Context, h inventory.Host) (*Conn, error) {
	hops, err := d.chain(h)
	if err != nil {
		return nil, err
	}
	var clients []*ssh.Client
	for _, hop := range hops {
		var via *ssh.Client
		if n := len(clients); n > 0 {
			via = clients[n-1]
		}
		c, err := d.dialHop(ctx, via, hop)
		if err != nil {
			for i := len(clients) - 1; i >= 0; i-- {
				clients[i].Close()
			}
			return nil, fmt.Errorf("%s: %w", hop.Name, err)
		}
		clients = append(clients, c)
	}
	n := len(clients)
	return &Conn{Client: clients[n-1], jumps: clients[:n-1]}, nil
}

// chain returns the hops to reach h, h last.
func (d *Dialer) chain(h inventory.Host) ([]inventory.Host, error) {
	var hops []inventory.Host
	if h.ProxyJump != "" {
		for _, spec := range strings.Split(h.ProxyJump, ",") {
			hop, err := d.resolveJump(strings.TrimSpace(spec))
			if err != nil {
				return nil, err
			}
			if hop.ProxyJump != "" && len(hops) == 0 {
				inner, err := d.chain(hop)
				if err != nil {
					return nil, err
				}
				hops = append(hops, inner...)
				continue
			}
			hops = append(hops, hop)
		}
	}
	if len(hops) > 8 {
		return nil, errors.New("ProxyJump chain longer than 8 hops")
	}
	return append(hops, h), nil
}

func (d *Dialer) resolveJump(spec string) (inventory.Host, error) {
	if d.Hosts != nil {
		if h, err := d.Hosts.Get(spec); err == nil {
			return h, nil
		}
	}
	h := inventory.Host{Name: spec, Port: 22}
	if at := strings.LastIndex(spec, "@"); at >= 0 {
		h.User, spec = spec[:at], spec[at+1:]
	}
	host, port, err := net.SplitHostPort(spec)
	if err != nil {
		host = spec
	} else if h.Port, err = strconv.Atoi(port); err != nil {
		return h, fmt.Errorf("bad ProxyJump port in %q", spec)
	}
	h.HostName = host
	return h, nil
}

func (d *Dialer) dialHop(ctx context.Context, via *ssh.Client, h inventory.Host) (*ssh.Client, error) {
	port := h.Port
	if port == 0 {
		port = 22
	}
	addr := net.JoinHostPort(h.HostName, strconv.Itoa(port))
	cfg, err := d.clientConfig(h, addr)
	if err != nil {
		return nil, err
	}
	var raw net.Conn
	if via == nil {
		nd := net.Dialer{Timeout: d.timeout()}
		raw, err = nd.DialContext(ctx, "tcp", addr)
	} else {
		raw, err = via.DialContext(ctx, "tcp", addr)
	}
	if err != nil {
		return nil, err
	}
	raw.SetDeadline(time.Now().Add(d.timeout()))
	c, chans, reqs, err := ssh.NewClientConn(raw, addr, cfg)
	if err != nil {
		raw.Close()
		return nil, explainHostKeyError(err, h)
	}
	raw.SetDeadline(time.Time{})
	return ssh.NewClient(c, chans, reqs), nil
}

func (d *Dialer) clientConfig(h inventory.Host, addr string) (*ssh.ClientConfig, error) {
	var files []string
	for _, f := range d.KnownHosts {
		if _, err := os.Stat(f); err == nil {
			files = append(files, f)
		}
	}
	if len(files) == 0 {
		return nil, errors.New("no known_hosts file found; connect once with plain `ssh` to record the host key")
	}
	db, err := knownhosts.NewDB(files...)
	if err != nil {
		return nil, err
	}
	name := h.User
	if name == "" {
		if u, err := user.Current(); err == nil {
			name = u.Username
		}
	}
	return &ssh.ClientConfig{
		User:              name,
		Auth:              []ssh.AuthMethod{ssh.PublicKeysCallback(d.signers(h))},
		HostKeyCallback:   db.HostKeyCallback(),
		HostKeyAlgorithms: db.HostKeyAlgorithms(addr),
		Timeout:           d.timeout(),
	}, nil
}

// signers offers ssh-agent keys first, then unencrypted key files.
func (d *Dialer) signers(h inventory.Host) func() ([]ssh.Signer, error) {
	return func() ([]ssh.Signer, error) {
		var out []ssh.Signer
		if d.AgentSocket != "" {
			if c, err := net.Dial("unix", d.AgentSocket); err == nil {
				if s, err := agent.NewClient(c).Signers(); err == nil {
					out = append(out, s...)
				}
			}
		}
		files := h.IdentityFiles
		if len(files) == 0 {
			files = d.DefaultKeys
		}
		for _, f := range files {
			b, err := os.ReadFile(f)
			if err != nil {
				continue
			}
			s, err := ssh.ParsePrivateKey(b)
			if err != nil {
				continue // passphrase-protected keys must be loaded into ssh-agent
			}
			out = append(out, s)
		}
		if len(out) == 0 {
			return nil, errors.New("no usable SSH key: load your key with `ssh-add` or set IdentityFile")
		}
		return out, nil
	}
}

func explainHostKeyError(err error, h inventory.Host) error {
	switch {
	case knownhosts.IsHostKeyChanged(err):
		return fmt.Errorf("HOST KEY CHANGED for %s — possible man-in-the-middle, refusing to connect: %w", h.HostName, err)
	case knownhosts.IsHostUnknown(err):
		return fmt.Errorf("host key for %s is not in known_hosts; connect once with `ssh %s` to verify and record it", h.HostName, h.Name)
	}
	return err
}

func (d *Dialer) timeout() time.Duration {
	if d.Timeout > 0 {
		return d.Timeout
	}
	return 15 * time.Second
}

// Result of one remote command.
type Result struct {
	Stdout    string
	Stderr    string
	ExitCode  int
	Truncated bool // output exceeded the capture limit
}

// Exec runs cmd in a new session. ctx cancellation kills the command.
// At most maxBytes of stdout and of stderr are kept.
func Exec(ctx context.Context, c *ssh.Client, cmd string, maxBytes int) (Result, error) {
	s, err := c.NewSession()
	if err != nil {
		return Result{}, err
	}
	defer s.Close()
	stdout, stderr := &capped{max: maxBytes}, &capped{max: maxBytes}
	s.Stdout, s.Stderr = stdout, stderr

	done := make(chan error, 1)
	go func() { done <- s.Run(cmd) }()
	select {
	case <-ctx.Done():
		s.Signal(ssh.SIGKILL)
		s.Close()
		return Result{}, fmt.Errorf("command stopped: %w", ctx.Err())
	case err = <-done:
	}
	res := Result{Stdout: stdout.String(), Stderr: stderr.String(), Truncated: stdout.over || stderr.over}
	var exitErr *ssh.ExitError
	switch {
	case err == nil:
	case errors.As(err, &exitErr):
		res.ExitCode = exitErr.ExitStatus()
	case errors.Is(err, &ssh.ExitMissingError{}):
		res.ExitCode = -1
	default:
		return res, err
	}
	return res, nil
}

type capped struct {
	bytes.Buffer
	max  int
	over bool
}

func (c *capped) Write(p []byte) (int, error) {
	if room := c.max - c.Len(); room < len(p) {
		c.over = true
		if room > 0 {
			c.Buffer.Write(p[:room])
		}
		return len(p), nil
	}
	return c.Buffer.Write(p)
}

				"set":   map[string]any{"type": "array", "items": map[string]any{"type": "string"}, "description": "tags to set, key=value"},
				"unset": map[string]any{"type": "array", "items": map[string]any{"type": "string"}, "description": "tag keys to remove"},
				"note":  map[string]any{"type": "string", "description": "replace the note"},
			},
			"required": []string{"host"},

		Assess: func(_ context.Context, raw json.RawMessage) (action.Assessment, error) {

				}
				keys = append(keys, k)
			}
			for _, k := range keys {
				if k == "env" || k == "ai_policy" {
					risk = action.Destructive
				}
			}
			preview := fmt.Sprintf("host %s: set %v, unset %v", in.Host, in.Set, in.Unset)
			if in.Note != nil {
				preview += fmt.Sprintf(", note %q", *in.Note)
			}
			return action.Assessment{Risk: risk, Targets: []action.Target{hostTarget(h)}, Preview: preview}, nil
		},
		Run: func(_ context.Context, raw json.RawMessage) (any, error) {
			var in tagInput
			if err := action.Decode(raw, &in); err != nil {
				return nil, err
			}
			var out inventory.Host
			err := p.Hosts.Update(func(m map[string]inventory.Host) error {
				h, ok := m[in.Host]
				if !ok {

				if h.Tags == nil {

					delete(h.Tags, k)
				}
				if in.Note != nil {

				}
				m[in.Host], out = h, h
				return nil
			})

		Summary: "Run a command on a saved SSH host",
		Description: "Run one non-interactive shell command on a saved SSH host and return the exit code, stdout and stderr. " +
			"Good for inspection: df -h, free -m, journalctl -u X -n 200, systemctl status X, ss -lntp. " +
			"Commands are risk-rated; changes on production or destructive commands need the user's approval — " +
			"never try to work around a denial. Do not start interactive programs or follow logs (tail -f); " +
			"raise timeout_sec for slow commands. Use sudo -n, never a password prompt. Respect the host's note.",
		Input: map[string]any{
			"type": "object",
			"properties": map[string]any{
				"host":        map[string]any{"type": "string", "description": "saved host name (see ssh_hosts_list)"},
				"command":     map[string]any{"type": "string", "description": "shell command line"},
				"timeout_sec": map[string]any{"type": "integer", "minimum": 1, "maximum": 600, "description": "default 60"},

			"required": []string{"host", "command"},
		},

		RestArgs:   true,

				return action.Assessment{}, err
			}
			if strings.TrimSpace(in.Command) == "" {
				return action.Assessment{}, fmt.Errorf("command is required")
			}
			h, err := p.Hosts.Get(in.Host)
			if err != nil {
				return action.Assessment{}, err
			}
			return action.Assessment{
				Risk:    policy.ClassifyCommand(in.Command),
				Targets: []action.Target{hostTarget(h)},
				Preview: fmt.Sprintf("%s (%s)$ %s", h.Name, describe(h), in.Command),
			}, nil
		},
		Run: func(ctx context.Context, raw json.RawMessage) (any, error) {
			var in execInput
			if err := action.Decode(raw, &in); err != nil {
				return nil, err
			}
			h, err := p.Hosts.Get(in.Host)
			if err != nil {
				return nil, err
			}
			timeout := time.Duration(in.TimeoutSec) * time.Second
			if in.TimeoutSec <= 0 {
				timeout = 60 * time.Second
			}
			ctx, cancel := context.WithTimeout(ctx, min(timeout, 600*time.Second))
			defer cancel()

			start := time.Now()
			conn, err := p.Dialer.Dial(ctx, h)
			if err != nil {
				return nil, err
			}
			defer conn.Close()
			res, err := sshx.Exec(ctx, conn.Client, in.Command, captureLimit)
			if err != nil {
				return nil, err
			}
			lim := shaper.Default
			if a, ok := action.ActorFrom(ctx); ok && a.Kind == action.Human {
				lim = humanLimits
			}
			out := ExecOutput{Host: h.Name, ExitCode: res.ExitCode, Capped: res.Truncated,
				DurationMs: time.Since(start).Milliseconds()}
			if out.Stdout, err = p.Artifacts.Shape(res.Stdout, lim); err != nil {
				return nil, err
			}
			if out.Stderr, err = p.Artifacts.Shape(res.Stderr, lim); err != nil {
				return nil, err
			}
			return out, nil
		},
	}
}

func describe(h inventory.Host) string {
	s := h.HostName
	if h.User != "" {
		s = h.User + "@" + s
	}
	if h.Port != 0 && h.Port != 22 {
		s = fmt.Sprintf("%s:%d", s, h.Port)

			keys = append(keys, k+"="+h.Tags[k])
		}
		sort.Strings(keys)
		s += " " + strings.Join(keys, ",")
	}
	return s
}

// native macOS dialog or on the terminal.
package confirm

import (
	"bufio"
	"context"
	"fmt"
	"io"
	"os/exec"

	"time"

	"github.com/hua-ri/coxswain/internal/approval"

// Message is the text shown to the human for an approval.
func Message(ap approval.Approval) string {
	return fmt.Sprintf("%s wants to run %s (%s risk):\n\n%s\n\nApproval id: %s",
		ap.Actor, ap.ActionID, ap.Risk, ap.Preview, ap.ID)
}

// Dialog shows a native dialog via osascript. Nobody answering within
// timeout yields Undecided, so the agent can fall back to `cox approve`.
func Dialog(timeout time.Duration) engine.Confirmer {
	return dialog(timeout, func(ctx context.Context, script string) (string, error) {
		out, err := exec.CommandContext(ctx, "osascript", "-e", script).Output()
		return string(out), err
	})
}

func dialog(timeout time.Duration, run func(context.Context, string) (string, error)) engine.Confirmer {
	return func(ctx context.Context, ap approval.Approval) engine.Verdict {
		ctx, cancel := context.WithTimeout(ctx, timeout+5*time.Second)
		defer cancel()
		out, err := run(ctx, DialogScript(ap, timeout))
		return ParseDialog(out, err)
	}
}

// DialogScript builds the AppleScript for an approval dialog.
func DialogScript(ap approval.Approval, timeout time.Duration) string {
	return fmt.Sprintf(`display dialog %s with title "Coxswain approval" buttons {"Deny", "Approve"} `+
		`default button "Deny" cancel button "Deny" giving up after %d with icon caution`,
		quote(Message(ap)), int(timeout.Seconds()))
}

// ParseDialog turns osascript's result into a verdict. The cancel button
// ("Deny") makes osascript exit non-zero.
func ParseDialog(out string, err error) engine.Verdict {
	if err != nil {
		if _, ok := err.(*exec.ExitError); ok {
			return engine.Denied // "Deny" is the cancel button
		}
		return engine.Undecided // osascript unavailable or killed
	}
	switch {
	case strings.Contains(out, "gave up:true"):
		return engine.Undecided
	case strings.Contains(out, "button returned:Approve"):
		return engine.Approved
	}
	return engine.Denied
}

func quote(s string) string {
	s = strings.ReplaceAll(s, `\`, `\\`)
	return `"` + strings.ReplaceAll(s, `"`, `\"`) + `"`
}

// Terminal asks on a terminal. Only an explicit "y" or "yes" approves.
func Terminal(in io.Reader, out io.Writer) engine.Confirmer {
	return func(_ context.Context, ap approval.Approval) engine.Verdict {
		fmt.Fprintf(out, "%s\n\nApprove? [y/N] ", Message(ap))
		line, _ := bufio.NewReader(in).ReadString('\n')
		switch strings.ToLower(strings.TrimSpace(line)) {
		case "y", "yes":
			return engine.Approved
		}
		return engine.Denied
	}
}

// Package cli builds the `cox` command tree. Every registered Action
// becomes a command (ssh.exec → `cox ssh exec`); approval commands are
// added by hand because only humans may use them.
package cli

import (
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"sort"
	"strings"

	"github.com/hua-ri/coxswain/internal/action"
	"github.com/hua-ri/coxswain/internal/engine"
	"github.com/spf13/cobra"
)

// Exit codes.
const (
	ExitOK       = 0
	ExitFailure  = 1
	ExitApproval = 3 // approval required or still pending
	ExitDenied   = 4
)

// ExitError carries a process exit code out of a command.
type ExitError struct{ Code int }

func (e ExitError) Error() string { return fmt.Sprintf("exit %d", e.Code) }

// Printer lets a result render itself on a terminal and choose the exit
// code (ssh.exec prints remote output and returns the remote exit code).
type Printer interface {
	PrintCLI(stdout, stderr io.Writer) int
}

type App struct {
	Engine  *engine.Engine
	Actor   action.Actor
	Confirm engine.Confirmer // nil: never ask interactively
	// HumanTTY is true when a human is at an interactive terminal; only
	// then may approvals be decided from the CLI.
	HumanTTY bool
	Stdin    io.Reader
	Stdout   io.Writer
	Stderr   io.Writer
	output   string
}

// NewRoot returns the root command with one command per Action plus the
// approval commands and any extra commands.
func NewRoot(app *App, version string, extra ...*cobra.Command) *cobra.Command {
	root := &cobra.Command{
		Use:           "cox",
		Short:         "Coxswain: an ops toolbox for you and your AI agents",
		Version:       version,
		SilenceUsage:  true,
		SilenceErrors: true,
	}
	root.PersistentFlags().StringVarP(&app.output, "output", "o", "text", "output format: text or json")
	root.SetIn(app.Stdin)
	root.SetOut(app.Stdout)
	root.SetErr(app.Stderr)

	for _, a := range app.Engine.Registry.List() {
		parent := root
		parts := strings.Split(a.ID, ".")
		for _, name := range parts[:len(parts)-1] {
			parent = child(parent, name)
		}
		parent.AddCommand(actionCommand(app, a, parts[len(parts)-1]))
	}
	root.AddCommand(approvalCommands(app)...)
	root.AddCommand(extra...)
	return root
}

// child returns parent's group command called name, creating it.
func child(parent *cobra.Command, name string) *cobra.Command {
	for _, c := range parent.Commands() {
		if c.Name() == name {
			return c
		}
	}
	c := &cobra.Command{Use: name, Short: name + " commands"}
	parent.AddCommand(c)
	return c
}

func actionCommand(app *App, a *action.Action, name string) *cobra.Command {
	props, _ := a.Input["properties"].(map[string]any)
	use := name
	for _, p := range a.Positional {
		use += " <" + p + ">"
	}
	cmd := &cobra.Command{Use: use, Short: a.Summary, Long: a.Description, Args: cobra.ArbitraryArgs}
	if a.RestArgs {
		cmd.Flags().SetInterspersed(false) // `cox ssh exec host df -h`: -h belongs to df
	}

	type flagVal struct {
		prop string
		get  func() any
	}
	var flags []flagVal
	names := make([]string, 0, len(props))
	for k := range props {
		names = append(names, k)
	}
	sort.Strings(names)
	for _, prop := range names {
		schema, _ := props[prop].(map[string]any)
		desc, _ := schema["description"].(string)
		flag := strings.ReplaceAll(prop, "_", "-")
		switch schema["type"] {
		case "integer":
			v := cmd.Flags().Int(flag, 0, desc)
			flags = append(flags, flagVal{prop, func() any { return *v }})
		case "boolean":
			v := cmd.Flags().Bool(flag, false, desc)
			flags = append(flags, flagVal{prop, func() any { return *v }})
		case "array":
			v := cmd.Flags().StringArray(flag, nil, desc)
			flags = append(flags, flagVal{prop, func() any { return *v }})
		default:
			v := cmd.Flags().String(flag, "", desc)
			flags = append(flags, flagVal{prop, func() any { return *v }})
		}
	}

	cmd.RunE = func(cmd *cobra.Command, args []string) error {
		in := map[string]any{}
		for _, f := range flags {
			if cmd.Flags().Changed(strings.ReplaceAll(f.prop, "_", "-")) {
				in[f.prop] = f.get()
			}
		}
		if err := mapPositional(a.Positional, a.RestArgs, args, in); err != nil {
			return err
		}
		raw, err := json.Marshal(in)
		if err != nil {
			return err
		}
		out := app.Engine.Invoke(cmd.Context(), app.Actor, a.ID, raw, app.Confirm)
		return app.render(out)
	}
	return cmd
}

// mapPositional assigns args to the Positional properties. With rest,
// the last property collects every remaining argument, joined by spaces.
func mapPositional(names []string, rest bool, args []string, in map[string]any) error {
	for i, arg := range args {
		switch {
		case rest && i == len(names)-1:
			restArgs := args[i:]
			if restArgs[0] == "--" { // flag parsing already stopped, so `--` is still here
				restArgs = restArgs[1:]
			}
			in[names[i]] = strings.Join(restArgs, " ")
			return nil
		case i >= len(names):
			return fmt.Errorf("unexpected arguments: %v", args[i:])
		}
		in[names[i]] = arg
	}
	return nil
}

func (app *App) render(out engine.Outcome) error {
	if app.output == "json" {
		enc := json.NewEncoder(app.Stdout)
		enc.SetIndent("", "  ")
		enc.Encode(out)
		return ExitError{exitCode(out)}
	}
	switch out.Status {
	case engine.StatusOK:
		switch r := out.Result.(type) {
		case Printer:
			return ExitError{r.PrintCLI(app.Stdout, app.Stderr)}
		case string:
			fmt.Fprintln(app.Stdout, r)
		default:
			enc := json.NewEncoder(app.Stdout)
			enc.SetIndent("", "  ")
			enc.Encode(r)
		}
	case engine.StatusApprovalRequired, engine.StatusApprovalPending:
		fmt.Fprintf(app.Stderr, "needs approval (%s risk): %s\napprove with: cox approve %s\nthen run:     cox approvals wait %s\n",
			out.Risk, out.Preview, out.ApprovalID, out.ApprovalID)
	case engine.StatusDenied:
		fmt.Fprintln(app.Stderr, "denied: "+out.Hint)
	default:
		fmt.Fprintln(app.Stderr, "error: "+out.Error)
	}
	return ExitError{exitCode(out)}
}

func exitCode(out engine.Outcome) int {
	switch out.Status {
	case engine.StatusOK:
		if p, ok := out.Result.(Printer); ok {
			return p.PrintCLI(io.Discard, io.Discard)
		}
		return ExitOK
	case engine.StatusApprovalRequired, engine.StatusApprovalPending:
		return ExitApproval
	case engine.StatusDenied:
		return ExitDenied
	}
	return ExitFailure
}

// Code extracts the exit code for main.
func Code(err error) int {
	if err == nil {
		return ExitOK
	}
	var e ExitError
	if errors.As(err, &e) {
		return e.Code
	}
	return ExitFailure
}

import (
	"context"
	"encoding/json"
	"fmt"

const instructions = `Coxswain (cox) gives you the user's ops tools: SSH hosts and remote commands.
- Start with ssh_hosts_list to see hosts, their tags (env=prod is production) and notes. Respect host notes.
- You never handle credentials; never ask the user for passwords or keys.
- Some actions need the user's approval. The user usually decides in a macOS dialog while your call waits.
  If a result says "approval_required", tell the user what you want to do and why, then call
  cox_approval_wait with the approval_id; it runs the action once approved.
- If an action is denied, do not try to reach the same result another way.
- Large outputs are truncated; read more with artifact_read.`

// ToolName maps an Action ID to an MCP tool name.
func ToolName(id string) string { return strings.ReplaceAll(id, ".", "_") }

// NewServer builds the MCP server. confirm (may be nil) is asked first
// when an action needs approval, e.g. a macOS dialog.
func NewServer(e *engine.Engine, actor action.Actor, confirm engine.Confirmer, version string) *sdk.Server {
	s := sdk.NewServer(&sdk.Implementation{Name: "cox", Version: version}, &sdk.ServerOptions{Instructions: instructions})
	for _, a := range e.Registry.List() {
		a := a
		s.AddTool(&sdk.Tool{
			Name:        ToolName(a.ID),
			Title:       a.Summary,
			Description: a.Description,
			InputSchema: a.Input,
		}, func(ctx context.Context, req *sdk.CallToolRequest) (*sdk.CallToolResult, error) {
			return result(e.Invoke(ctx, actor, a.ID, req.Params.Arguments, confirm)), nil
		})
	}
	s.AddTool(&sdk.Tool{
		Name:  "cox_approval_wait",
		Title: "Wait for the user's approval",
		Description: "Wait until the user approves or denies a pending action (approval_id from an approval_required result). " +
			"If approved, the action runs and its result is returned. If still pending after timeout_sec, call again.",
		InputSchema: map[string]any{
			"type": "object",
			"properties": map[string]any{
				"approval_id": map[string]any{"type": "string"},
				"timeout_sec": map[string]any{"type": "integer", "minimum": 1, "maximum": 300, "description": "default 45"},
			},
			"required": []string{"approval_id"},
		},
	}, func(ctx context.Context, req *sdk.CallToolRequest) (*sdk.CallToolResult, error) {
		var in struct {
			ApprovalID string `json:"approval_id"`
			TimeoutSec int    `json:"timeout_sec"`
		}
		if err := action.Decode(req.Params.Arguments, &in); err != nil {
			return result(engine.Outcome{Status: engine.StatusError, Error: err.Error()}), nil
		}
		timeout := 45 * time.Second
		if in.TimeoutSec > 0 {
			timeout = time.Duration(min(in.TimeoutSec, 300)) * time.Second
		}
		if _, err := e.Wait(ctx, in.ApprovalID, timeout, 500*time.Millisecond); err != nil {
			return result(engine.Outcome{Status: engine.StatusError, Error: err.Error()}), nil
		}
		return result(e.RunApproved(ctx, actor, in.ApprovalID)), nil
	})
	return s
}

func result(out engine.Outcome) *sdk.CallToolResult {
	switch out.Status {
	case engine.StatusApprovalRequired:
		out.Hint = fmt.Sprintf("Needs the user's approval. Explain to the user what you want to do and why, then call "+
			"cox_approval_wait with approval_id=%s. The user can also approve in a terminal with `cox approve %s`.",
			out.ApprovalID, out.ApprovalID)
	case engine.StatusApprovalPending:
		out.Hint = "Still waiting for the user. Call cox_approval_wait again, or ask the user to decide."
	}
	b, err := json.MarshalIndent(out, "", "  ")
	if err != nil {
		b = []byte(fmt.Sprintf(`{"status":"error","error":%q}`, err.Error()))
	}
	return &sdk.CallToolResult{
		Content: []sdk.Content{&sdk.TextContent{Text: string(b)}},
		IsError: out.Status == engine.StatusError || out.Status == engine.StatusDenied,
	}
}

# Coxswain (cox)

Coxswain holds the user's SSH hosts and credentials and enforces their approval policy.
Use it for every remote operation. Never ask the user for passwords or keys, and never
use raw `ssh` to reach hosts that Coxswain manages.

## Tools

Prefer the MCP tools when they are available:

| Tool | Use |
|---|---|
| `ssh_hosts_list` | hosts with tags (`env=prod` is production) and notes |
| `ssh_exec` | run one non-interactive command on a host |
| `artifact_read` | read more of a truncated output (`grep`, `start`/`end`) |
| `cox_approval_wait` | wait for the user's decision on a pending action |

Without MCP, use the CLI with JSON output:

```bash
cox -o json ssh hosts list
cox -o json ssh exec <host> -- <command>
cox -o json artifact read <artifact-id> --grep ERROR
cox -o json approvals wait <approval-id>
```

## Rules

1. Look before you act: list hosts, read the host note, inspect state with read-only commands first.
2. A host note can forbid things ("no restarts during business hours"). Follow it; if it blocks the task, tell the user.
3. Changes may need approval. Usually a macOS dialog appears and your call waits. If you get
   `approval_required`, tell the user exactly what you want to run and why, then call
   `cox_approval_wait` (or `cox approvals wait <id>`). Never run `cox approve` yourself.
4. If an action is denied, do not reach the same result another way. Offer a safer alternative or stop.
5. Use `sudo -n`, never a password prompt. Do not start interactive programs or `tail -f`.
6. Outputs over ~200 lines are truncated; read the rest with `artifact_read` instead of re-running.

func (i *Installer) kimi() Result {
	r := Result{Agent: "Kimi Code"}
	home := i.KimiHome
	if home == "" {
		home = filepath.Join(i.UserHome, ".kimi-code")
	}
	if _, err := i.LookPath("kimi"); err != nil {
		if _, statErr := os.Stat(home); statErr != nil {
			r.MCP = "skipped: kimi not found"
			return r
		}
	}
	path := filepath.Join(home, "mcp.json")
	cfg := map[string]any{}
	b, err := os.ReadFile(path)
	switch {
	case errors.Is(err, os.ErrNotExist):
	case err != nil:
		r.Err = err
		return r
	case len(b) > 0:
		if err := json.Unmarshal(b, &cfg); err != nil {
			r.Err = fmt.Errorf("%s is not valid JSON, not touching it: %w", path, err)
			return r
		}
	}
	servers, _ := cfg["mcpServers"].(map[string]any)
	if servers == nil {
		servers = map[string]any{}
	}
	servers["cox"] = map[string]any{"command": i.Exe, "args": []string{"mcp", "--actor", "kimi"}}
	cfg["mcpServers"] = servers
	out, _ := json.MarshalIndent(cfg, "", "  ")
	if r.Err = atomicWrite(path, append(out, '\n')); r.Err != nil {
		return r
	}
	r.MCP = "registered in " + path
	r.Skill, r.Err = writeSkill(filepath.Join(home, "skills"))
	return r
}

func writeSkill(skillsDir string) (string, error) {
	path := filepath.Join(skillsDir, "cox", "SKILL.md")
	return path, atomicWrite(path, Skill)
}

func atomicWrite(path string, b []byte) error {
	if err := os.MkdirAll(filepath.Dir(path), 0o700); err != nil {
		return err
	}
	tmp := path + ".tmp"
	if err := os.WriteFile(tmp, b, 0o600); err != nil {
		return err
	}
	return os.Rename(tmp, path)
}

func initCommand(app *cli.App, userHome string) *cobra.Command {
	var skipImport, skipAgents bool
	cmd := &cobra.Command{
		Use:   "init",
		Short: "Import ~/.ssh/config and connect Claude Code, Codex and Kimi Code",
		Args:  cobra.NoArgs,
		RunE: func(cmd *cobra.Command, _ []string) error {
			out := cmd.OutOrStdout()
			if !skipImport {

					res := app.Engine.Invoke(cmd.Context(), app.Actor, "ssh.hosts.import", nil, app.Confirm)

					}

				}

				return nil

			exe, err := exePath()

					c := exec.CommandContext(cmd.Context(), name, args...)

						return fmt.Errorf("%s %v: %w: %s", name, args, err, b)
					}
					return nil
				},
			}
			failed := false
			for _, r := range i.All() {
				switch {
				case r.Err != nil:
					failed = true
					fmt.Fprintf(out, "%-12s error: %v\n", r.Agent, r.Err)
				case r.Skill != "":
					fmt.Fprintf(out, "%-12s MCP %s; skill %s\n", r.Agent, r.MCP, r.Skill)
				default:
					fmt.Fprintf(out, "%-12s %s\n", r.Agent, r.MCP)
				}
			}
			if failed {
				return errors.New("some agents were not set up")
			}
			fmt.Fprintln(out, "done. Restart your agents to load the cox tools.")
			return nil
		},
	}
	cmd.Flags().BoolVar(&skipImport, "skip-import", false, "do not import ~/.ssh/config")
	cmd.Flags().BoolVar(&skipAgents, "skip-agents", false, "do not configure AI agents")
	return cmd
}

// exePath prefers the PATH entry for cox (e.g. /opt/homebrew/bin/cox) over
// the resolved binary, so agent configs survive `brew upgrade`.
func exePath() (string, error) {
	self, err := os.Executable()
	if err != nil {
		return "", err
	}
	if p, err := exec.LookPath("cox"); err == nil {
		a, errA := os.Stat(p)
		b, errB := os.Stat(self)
		if errA == nil && errB == nil && os.SameFile(a, b) {
			if abs, err := filepath.Abs(p); err == nil {
				return abs, nil
			}
		}
	}
	return self, nil
}

# Coxswain (`cox`)

An ops toolbox for you **and your AI agents**. Coxswain keeps your SSH hosts, credentials
and approval policy in one place, and gives Claude Code, Codex and Kimi Code safe access to
them over MCP — risky actions wait for your approval in a native macOS dialog.

> macOS only. Personal use. Early: M0 covers SSH hosts and remote commands.
> Kubernetes, Argo CD / Argo Workflows and the desktop app (`cox desktop`) are next.

## Install

```bash
brew install hua-ri/tap/coxswain
# or
curl -fsSL https://raw.githubusercontent.com/hua-ri/coxswain/main/install.sh | sh
```

## Quick start

```bash
cox init                              # import ~/.ssh/config, connect Claude Code / Codex / Kimi
cox ssh hosts list
cox ssh hosts tag prod-web-01 --set env=prod --note "no restarts 9:00-18:00"
cox ssh exec prod-web-01 -- df -h
```

Then ask your agent, e.g. *"Why is the disk on prod-web-01 filling up?"* It uses the `cox`
tools; anything that changes a production host, or anything destructive anywhere, pops up an
approval dialog first.

## How approvals work

| | read | write | destructive |
|---|---|---|---|
| you, in a terminal | runs | runs | asks `[y/N]` |
| agent, normal host | runs | runs | asks |
| agent, `env=prod` host | runs | asks | asks |

- Commands are parsed (not pattern-matched) to rate them; anything that cannot be understood
  counts as destructive.
- An approval is bound to the exact command, used once, and expires after 30 minutes.
- If nobody answers the dialog, approve later with `cox approvals` / `cox approve <id>`.
  Agents cannot approve their own actions.
- Tag a host `ai_policy=always|balanced|auto` to override its mode.

Everything is recorded in `~/.coxswain/events/YYYY-MM-DD.jsonl`.

## Files

| Path | What |
|---|---|
| `~/.coxswain/hosts.json` | hosts, tags, notes |
| `~/.coxswain/approvals/` | pending and decided approvals |
| `~/.coxswain/events/` | audit log |
| `~/.coxswain/artifacts/` | full copies of truncated outputs |

## Execution log (2026-11-07)

Tasks 1–18 executed; every file matched the plan verbatim. A code-quality/security review of the result then found
approval bypasses (state-changing commands rated Read, agent detection failing open for non-TTY callers, alias
import bypassing host tags, self-approval through a detached pty, spoofable previews, approver misrecorded,
ProxyJump cycles, unlocked hosts.json). Fixed in commits `25dd0d9..69c4620` (spec: G1–G9 + re-review N1–N5);
a re-review confirmed every finding fixed. Behaviour that changed from the plan text above:

- `actor.Detect(tty)`: a non-interactive caller with no known agent ancestor is `agent:unknown`.
- `cox approve` approves only via the macOS dialog button; `Confirmer` returns the deciding actor.
- Import from a non-default path and note changes are Destructive; new aliases inherit tags/note from the
  strictest host at the same address; the import preview shows `name -> user@host:port`.
- `internal/filelock` guards `hosts.json` and approvals across processes.
- The classifier checks arguments of many commands (ip, sysctl, sed, awk, sort, git …), inner commands (ssh,
  su -c, docker/kubectl exec, find -exec, every `-c`), env-var prefixes, and protected paths after `path.Clean`.

### Follow-ups for v0.1.x (non-blocking, from the re-review)

- Import binds the path, not the file content: store parsed hosts or a file hash in the approval (N6).
- Same-address inheritance compares literal HostName (`localhost` ≠ `127.0.0.1`, DNS ≠ IP).
- More protected paths (`/dev/xvda`, `/dev/mapper/*`, `/dev/md*`, `~/.bashrc`, `~/.profile`) and wrappers
  (`chroot`, `nsenter`, `unshare`, `strace`, `script -c`, `tmux`, `screen`, `at`, `parallel`, `busybox`,
  `perl -e`, `python -c`, `ksh -c`, `fish -c`, `docker -H … exec`, `nerdctl`/`crictl exec`) (N7).
- Read-list additions so common diagnostics stop needing approval on prod: `kubectl get/describe/logs`,
  `docker compose ps`, `docker stats --no-stream`, `openssl … -noout`, `curl -sI`.
- Secrets typed into commands are stored in the audit log and approvals; add redaction (design §4.7).
- Artifacts are never cleaned up; add retention.
