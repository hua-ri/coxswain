## Issues found

1. **Killed dialog recorded as a human denial.** Interrupting the requesting process killed `osascript`; any
   non-zero exit is parsed as Deny, so the log says `human:king/dialog denied` although nobody clicked.
   Only the cancel button (error -128) may count as Deny; anything else → Undecided (stays pending).
2. **Approval orphaned across sessions.** An approval granted with `cox approve` after the agent's session ended
   cannot be used by a new session (session binding). Safe, but the user's click is wasted. Options: let a new
   session of the same agent consume it within TTL, or say so in the hint.
3. **Codex blocks MCP tools in `codex exec`.** Codex asks for its own approval on every MCP tool call; in
   non-interactive mode that is a hard failure. `cox init` should write
   `default_tools_approval_mode = "approve"` under `[mcp_servers.cox]` (cox does the approving).
4. **`[ … ]` rated Write.** `if [ -e f ]; then ls -ld f; fi` asked on prod. Add `[` (alias of `test`) to the
   read-only list.

Environment notes (not cox): Codex's `codex-code-mode-host` was quarantined by Gatekeeper (Homebrew cask,
unnotarized); fixed by clearing its quarantine flag. Claude Code's gateway intermittently returned
`400 context_management: Extra inputs are not permitted`; retries succeeded.
